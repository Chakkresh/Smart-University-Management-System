# Smart University Management System (SUMS)

A ServiceNow-based university management system for admissions, fees, campus services, leave approvals, and automated notifications.

## Project Overview

Smart University Management System (SUMS) is a ServiceNow application designed to manage important university processes through a centralized platform.

The system covers student admission, document verification, admission approval, fee management, hostel allocation, transport allocation, student leave/pass requests, notifications, security, and reporting.

## Main Modules

- Student Application
- Document Verification
- Admission Approval
- Student Master
- Fee Management
- Hostel Management
- Transport Management
- Leave / Out Pass / Special Permission
- Approval Workflows
- Email Notifications
- Reports
- Dashboard
- Role-Based Access Control
